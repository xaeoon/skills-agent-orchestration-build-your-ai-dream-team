# 에이전트 팀

Mona의 Project Pulse 대시보드를 구축하기 위해 GitHub Copilot CLI를
Codespace에서 사용해 네 명의 에이전트를 조율한다. 오케스트레이터는 전체
작업을 조정하고, 기획자는 요구사항과 구현 순서를 정리하며, 코더는 기능을
구현하고, 디자이너는 대시보드의 사용자 경험과 시각적 완성도를 담당한다.

| 에이전트 | 할당된 모델 | 책임 | 에이전트 정의 파일 |
| --- | --- | --- | --- |
| 오케스트레이터 (Orchestrator) | Claude Opus 4.7 (copilot) | 기획자, 코더, 디자이너에게 작업을 배정하고 파일 범위와 의존성을 관리하며, 통합 결과를 확인한다. | `.github/agents/orchestrator.agent.md` |
| 기획자 (Planner) | Claude Opus 4.7 (copilot) | 저장소와 요구사항을 조사하고, 위험 요소와 예외 상황을 파악하며, 구현 순서와 파일별 작업 계획을 작성한다. | `.github/agents/planner.agent.md` |
| 코더 (Coder) | GPT-5.5 (copilot) | 할당된 애플리케이션 코드를 구현하고, 필요한 실행 설정을 추가하며, 결정적이고 테스트 가능한 동작을 검증한다. | `.github/agents/coder.agent.md` |
| 디자이너 (Designer) | Gemini 3.1 Pro (copilot) | 정보 구조, 접근성, 반응형 동작, 프로젝트 카드, 상태 배지, 우선순위 표현, 시각적 스타일을 설계한다. | `.github/agents/designer.agent.md` |

## 협업 방식

1. 오케스트레이터가 먼저 기획자에게 저장소와 요구사항을 조사하도록 요청한다.
2. 기획자는 구현 단계, 파일 할당, 의존성, 위험 요소와 검증 기준을 정리한다.
3. 오케스트레이터는 파일 범위가 겹치지 않는 기획·디자인 작업을 병렬로
   진행하고, 선행 결과가 필요한 코딩 작업은 순차적으로 배정한다.
4. 디자이너는 Project Pulse 대시보드의 정보 계층과 UI 방향을 제시하고,
   코더는 그 방향에 맞춰 애플리케이션과 실행 구성을 구현한다.
5. 오케스트레이터가 결과물을 통합해 요구사항과 파일 범위가 모두 충족되는지
   확인하고 최종 상태를 보고한다.
